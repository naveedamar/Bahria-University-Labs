# OOP Lab 01

## 📘 Tasks

1. **Data Types**  
   Program demonstrating data types in Java.

2. **Calculator**  
   Simple calculator using `switch` case (Addition, Subtraction, Multiplication, Division).

3. **Prime Numbers**  
   Print all prime numbers between 1 to 1000.

4. **Linear Search**  
   Implement linear search in a 1D array.

5. **Reverse String**  
   Reverse a string entered by the user.

6. **Larger of Two Integers**  
   Accept two integers, return the larger one (or handle special cases as per conditions).

7. **First & Last Element Comparison**  
   Get larger value between the first and last element of an array of length 3.

8. **Matrix Multiplication**  
   Multiply 2 matrices in Java.

9. **Recursion**  
   Implement recursion in Java.
