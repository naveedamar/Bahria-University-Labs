# 🏛️ CSC 327: Computer Architecture - Lab 6

## 🎯 Objective
Understand MIPS array implementation, indexed addressing, and manual memory offset calculation.

## 📝 Tasks Completed
* **Task 1: Array Printing:** Used a loop and a base pointer to iterate and print predefined array elements.
* **Task 2: Array Summation:** Iterated through an array and accumulated the values in a register.
* **Task 3: Find Maximum:** Compared array elements in a loop to identify and print the largest value.
* **Open-Ended Task:** Created a program to read $N$ user inputs into an array and print them in reverse order.

## 🏁 Conclusion
Learned to manage data structures in memory by manually calculating offsets and using pointers to navigate arrays in both forward and reverse directions.
