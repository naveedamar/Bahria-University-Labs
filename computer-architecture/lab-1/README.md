# 🏛️ CSC 327: Computer Architecture - Lab 1

## 🎯 Objective
To learn the MARS simulator interface, MIPS registers (`$zero`, `$v0`, `$a0`), and basic system calls.

## 🛠️ Commands Learned
- `li`: Load Immediate.
- `la`: Load Address.
- `syscall`: Trigger system services (print, exit).

## 📝 Tasks Completed
- **Task 1 & 2:** Printed single and multiple strings to the console.
- **Task 3:** Printed characters using ASCII values.
- **Open-Ended:** Stored and printed an integer (50).

## 🧠 Quiz Insights
- `$v0` specifies the syscall type (e.g., 4 for string, 1 for int).
- `$a0` holds the argument/value to print.
- `.data` segment is for static memory allocation (constants, strings).

## 🏁 Conclusion
I gained hands-on experience with MARS, MIPS register conventions, and basic Input/Output operations.
