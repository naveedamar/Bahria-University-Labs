# 🖥️ Computer Architecture Labs

This directory contains my lab work and projects for Computer Architecture.
The goal is to transition from basic assembly programming  to understanding hardware design, processor optimization, and the RISC (Reduced Instruction Set Computer) philosophy using the MIPS architecture.

> **Note:** All programs are written in MIPS Assembly and tested using the MARS / QtSpim simulator.
> 
> EMU8086, covered in the previous semester [Computer Organization and Assembly Language](../computer-organization-and-assembly-language)
---

## 📚 Topics Covered
* Introduction to MIPS Architecture & RISC Principles
* MIPS Register Conventions ($t0-$t9, $s0-$s7, $a0-$a3, $v0-$v1)
* Load/Store Memory Operations (lw, sw)
* Arithmetic and Logical Operations
* Control Flow (Branches and Jumps)
* Procedures and Stack Management
* System Calls (syscall) for I/O
* Floating-Point Coprocessor Operations
* Datapath and Pipelining Concepts (Theory to Code)
---
## ⚙️ Tools
* **Emulator:** MARS (MIPS Assembler and Runtime Simulator) or QtSpim
* **Architecture:** 32-bit MIPS (RISC)
---
## 🚀 How to Run (using MARS)
1. Open the MARS simulator.
2. Open the `.asm` or `.s` file.
3. Click **Run -> Assemble** (or press F3) to compile the code.
4. Click **Run -> Go** (or press F5) to execute.
5. View the program output in the **Run I/O** tab at the bottom of the screen.
