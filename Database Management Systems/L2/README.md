# 📘 DBMS Lab 02 – Querying the Tables

This lab builds on the basics of SQL by introducing the **`WHERE`** and **`ORDER BY`** clauses in the `SELECT` statement. The goal is to learn how to filter, sort, and query data effectively.

---

## 🎯 Objectives
- Learn to filter rows using the `WHERE` clause.  
- Apply logical conditions and pattern matching in queries.  
- Sort query results using the `ORDER BY` clause.  

---

## 📝 Exercises

Using the **Student_DataSet.sql** database, formulate the following queries:

1. Select all **theory-based courses** that belong to the Computer Science program from the `Course` table.  
2. List the names of all students whose names start with the letter **‘A’**.  
3. Display all **lab-based courses** that are being taught in either the Computer Science program or IT program.  
4. Display the names and salaries of teachers whose salary lies in the range of **100K to 200K**.  
5. Display the names and designations of teachers whose manager field is **empty**.  
6. Display the names of all students that end with the letter **‘N’**.  
7. Show the name, salary, and job of those faculty members who are **not visiting** and whose job is not **Junior Lecturer**.  
8. Show all students whose names **do not start with ‘M’, ‘A’, or ‘S’**.  
9. Show the names of students whose names **start with ‘A’ and end with ‘R’**.  
10. Display the list of employee names that have the substring **‘MO’** in their names.  
11. Display all students **ordered by their names**.  
12. Display all faculty members **ordered by their salaries**, from the highest to the lowest.  

---

## 📂 Notes
- Database used: **Student_DataSet.sql**  
- Core focus: Learning how to **filter and order results** in SQL queries.
