# 📘 Lab05: Joining Tables

## 🎯 Objectives
Learn to use **JOINS** in `SELECT` statements.

## 📝 Exercises
Using the **StudentInformation** database, write SQL queries for:

1. Select **CourseID, CourseName, ProgramName** using `Course` and `Prog` tables.  
2. Select **CourseID, CourseName, ProgramName, SemesterName** using `Course`, `Prog`, and `Semester` tables.  
3. Select **StdID, StdName** who are in programs other than **BSCS**.  
4. Select all **visiting faculty names** and the **course names** taught by them.  
5. Select all courses taught by **Dr. Iman in Fall2023**.  
6. Select all courses (**CourseID, CourseName**) along with their **teacher names**. Show all course records.  
7. Select all **student names** taught by **Dr. Ahmed** along with the **Course Name**.  
8. Select **StdID, StdName, CourseID, CourseName, TeacherID, TeacherName, SemID, SemesterName**.  
9. Select distinct **TeacherID, TeacherName** of teachers who taught any course in **Fall2023**.  
10. Select all **TeacherID and TeacherName** who taught any course in any program.  
11. Select all **TeacherID, TeacherName, CourseName** who taught any course in any program. Include all teacher records.  
12. Select all **TeacherID, TeacherName, CourseID, SemID** of teachers who have **not taught** any course.  
13. Select **SemesterID, SemesterName, Number of enrolled students** where **no student is enrolled** in any course.
