# 📘 DBMS Lab 01 – Foundation Statements of SQL

This lab introduces the fundamentals of SQL by practicing the **`SELECT`** statement and basic retrieval queries.

---

## 🎯 Objectives
- Learn the syntax and usage of the `SELECT` statement.  
- Retrieve data from single tables.  
- Perform simple aggregations and filtering.  

---

## 📝 Exercises

Using the **Student_DataSet.sql** database, formulate the following queries:

1. Get `StdID`, `StdName`, `StdDOB`, `StdPhone`, and `ProgID` from the `Std` table.  
2. Count the total number of students.  
3. Select all **permanent teachers** from the `Teacher` table.  
4. Display all the **Program IDs** (without repetition) that have students enrolled, from the `Std` table.  
5. Display the data of all students who belong to **ProgramID = 1**.  
6. Display the names of students who belong to **ProgramID = 1**.  
7. Calculate the **one-year salary** of all teachers from the `Teacher` table.  
8. Display the **total count of programs** from the `Prog` table.  
9. Display all faculty names and their manager numbers from the `Teacher` table.  

---

## 📂 Notes
- Database used: **Student_DataSet.sql**  
- Core focus: Learning the **basics of `SELECT`** queries in SQL.
