# ⚡ DSA Lab 09 – Implementation of Quick Sort and Merge Sort

---

## 🎯 Objectives

By completing this lab, students will be able to:

* Understand and implement **Quick Sort** and **Merge Sort** algorithms in C++.
* Apply sorting algorithms to **real-world data** such as ages, files, and names.
* Compare the efficiency of different sorting methods for various data types.
* Strengthen problem-solving skills related to **divide-and-conquer** algorithms.

---

## 📝 Exercises

### 1. Age Sorter – Summer Camp Registration

You are the lead organizer of a **summer camp** and must arrange students’ records by **age (youngest to oldest)** using
both **Quick Sort** and **Merge Sort**.

#### Dataset:

| Name | Age | Name   | Age | Name   | Age |
|------|-----|--------|-----|--------|-----|
| Ali  | 14  | Zara   | 18  | Rameen | 13  |
| Zara | 17  | Faraz  | 14  | Jamil  | 12  |
| Hira | 15  | Danial | 16  | Asif   | 17  |
| Saba | 19  | Namra  | 11  | Sameen | 10  |

#### Tasks:

1. Implement **Quick Sort** to arrange students by age.
2. Implement **Merge Sort** to do the same.
3. Display the list sorted from **youngest to oldest**.

#### Goal:

To demonstrate sorting efficiency on **numerical data** (students’ ages).

---

### 2. System Files Sorting – Alphabetical File Management

You are a **software engineer** optimizing the company’s file storage system.  
Use **Quick Sort** to organize **file names alphabetically**, improving search and access speed.

#### Tasks:

1. Implement Quick Sort for **alphabetical string sorting**.
2. Simulate file organization for a corporate environment.

#### Goal:

To improve **retrieval time** and manage **large-scale digital data** efficiently.

---

### 3. Running Speed Sorter – Marathon Ranking

In a marathon event, each runner’s **average running speed** is recorded.  
You must rank participants from **slowest to fastest** using **Merge Sort**.

#### Data:

`{2.4, 0.9, 0.6, 5.1, 8.0, 2.2, 8.6, 4.3, 6.7, 7.9, 5.4, 3.2, 9.5, 5.5}`

#### Tasks:

1. Implement **Merge Sort** for floating-point numbers.
2. Display participants ranked from **lowest to highest speed**.

#### Goal:

To efficiently rank participants using **Merge Sort on decimal data**.

---

### 4. E-Books Sorting App – Bahria University Library

Bahria University wants to modernize its **E-Library** by organizing all e-books **alphabetically**.  
Use both **Quick Sort** and **Merge Sort** to arrange book titles for better accessibility.

#### Dataset:

`{Design And Analysis of Computer Algorithms, Compilers: Techniques And Tools, Data Structures and Algorithms, Fundamental of Mathematics, Computer Communications and Networking, Artificial Intelligence, Principles of Compiler Design, Cloud Computing and Software Services, Visual Basic .Net Programming, Oracle Database 11g: New Features for DBAs and Developers, Online Training: The New Age Training Method, Applied Calculus and Analytical Geometry}`

#### Tasks:

1. Implement **Quick Sort** and **Merge Sort** for **strings**.
2. Sort books **alphabetically (A–Z)**.
3. Display sorted results for both algorithms.

#### Goal:

To demonstrate sorting algorithms on **textual data** for **library systems**.

---

## 📂 Key Concepts

* **Quick Sort** – Divide and conquer sorting using pivot partitioning.
* **Merge Sort** – Recursive divide and merge sorting algorithm.
* Sorting **integers**, **floating-point numbers**, and **strings**.
* Real-world applications of sorting algorithms in:
    - **Student data systems**
    - **File management**
    - **Sports ranking**
    - **Digital library organization**
