# ✈️ DSA Assignment 3 – Airline Ticket Reservation System

### 🎯 Objectives

By completing this assignment, students will be able to:

- **Apply Linked List data structures** to solve real-world problems.  
- **Design menu-driven programs** using fundamental data structure concepts.  
- **Manage dynamic data efficiently** using pointers and linked lists.  
- **Demonstrate problem-solving depth** through conceptual and structured solutions.  

---

## 📝 Assignment Overview

This assignment focuses on designing an **Airline Ticket Reservation System** using **Linked Lists**.  
The system must manage passenger reservations efficiently while maintaining data in **alphabetical order**.

Students are required to implement **two versions** of the system, progressing from a simple to a more advanced design.

---

## 🧪 Programs

### 1. Single Flight Reservation System (Simple Version)

In this version, the airline operates **only one flight**.

Passenger information is stored in an **alphabetized linked list**.

#### **Menu Options**
- Reserve a ticket  
- Cancel a reservation  
- Check if a ticket is reserved for a specific person  
- Display all passengers  

#### **Goal**
To understand how linked lists can be used to manage ordered data dynamically for a single entity.

---

### 2. Multiple Flights Reservation System (Full Version)

In this version, the airline can operate **multiple flights** with **no limit**.

- Flights are stored in a **linked list**.
- Each flight node contains a **pointer to another linked list of passengers**.
- Passenger lists are maintained in **alphabetical order**.

#### **Menu Options**
- Reserve a ticket for a specific flight  
- Cancel a reservation  
- Check if a passenger is reserved on a flight  
- Display passengers of a selected flight  

#### **Goal**
To apply **nested linked lists** and demonstrate advanced data structure usage for scalable systems.
