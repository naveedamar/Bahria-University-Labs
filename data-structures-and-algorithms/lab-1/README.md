# 📘 DSA Lab 01 – Implementation of Arrays  

**Course:** CSL-221 Data Structures & Algorithms  

---

## 🎯 Objectives  
By completing this lab, students will be able to:  
- Insert an element in an array  
- Delete an element from an array  
- Traverse an array  

---

## 📝 Exercises  

1. **Delivery Trucks 🚚**  
   Manage an array of truck IDs for a shipping company:  
   - Insert truck ID `1011` at position 5  
   - Traverse and display the array  
   - Delete the truck ID at position 9  

2. **Employee Record 👨‍💼**  
   Use an array of employee joining years:  
   - Calculate years spent in the company (current year = 2025)  
   - Find and print the oldest and most recent employee  
   - Count employees with more than 10 years of experience  

3. **Fitness Tracking App 🏃**  
   Track exercise minutes of 10 users:  
   - Find all pairs summing to 25 minutes  
   - Count even and odd exercise minutes  
   - Display maximum and minimum exercise time  
   - Calculate average exercise minutes  

4. **Library Books Record 📚**  
   Maintain book titles in a list:  
   - Insert a new book into the list  
   - Count the total number of books  
   - Reverse the order of the books  

---

## 📂 Key Concepts  
- Array Insertion  
- Array Deletion  
- Array Traversal  
- Real-world applications of arrays (fleet management, employee data, fitness tracking, library systems)
