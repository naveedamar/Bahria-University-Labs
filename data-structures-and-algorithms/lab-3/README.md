# 🧮 DSA Lab 03 – Sorting Algorithms

**Course:** CSL-221 Data Structures & Algorithms

---

## 🎯 Objectives
By completing this lab, students will be able to:
- Implement the following sorting algorithms in C++:
  - **Bubble Sort**
  - **Selection Sort**
  - **Insertion Sort**

---

## 📝 Exercises

1. **Gaming Leaderboards**  
   Implement Bubble Sort, Selection Sort, and Insertion Sort to arrange player scores:  
   `{450, 320, 550, 290, 400, 610, 370, 480, 540, 300}`  
   - Print the array after each pass.  
   - Display total number of passes and comparisons.  
   - Show the final sorted result.  

2. **File Management System**  
   Create a program that uses **Bubble Sort** to sort file names (strings) in ascending alphabetical order.  

3. **Currency Sort Challenge**  
   Use **Insertion Sort** to organize a messy stack of currency notes in ascending order. Assume input size and note values as needed.  

4. **E-commerce Application**  
   Implement **Selection Sort** to handle a product list (name, price, rating).  
   - Sort products by **price** (ascending).  
   - Sort products by **rating** (descending).  

5. **Music Playlist Manager**  
   Use **Insertion Sort** to sort songs in a playlist by **duration (in seconds)** in ascending order.  

---

## 📂 Key Concepts
- Bubble Sort, Selection Sort, Insertion Sort  
- Sorting numbers, strings, and structured data  
- Applications in **gaming, file systems, finance, e-commerce, and music streaming**
