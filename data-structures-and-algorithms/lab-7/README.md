# 🧮 DSA Lab 07 – Implementation of Single Linked List  

---

## 🎯 Objectives  

By completing this lab, students will be able to:  

* Understand and implement the **concept of a singly linked list** in C++.  
* Perform basic operations such as **insertion**, **traversal**, **deletion**, and **searching** in a linked list.  
* Apply linked lists in **real-world simulations** such as social media feeds, queue management systems, and transportation routes.  

---

## 📝 Exercises  

### 1. News Feed – Social Media System  

Create a **News Feed System** using a **Singly Linked List** where each node represents a post with:  
- **Post Content**  
- **Timestamp**  

#### Operations:
1. Add a new post at the **beginning** of the feed.  
2. Remove a post by its **content**.  
3. Display all posts in **chronological order**.  
4. Display the **total count** of posts.  
5. Search for a post by **content**.  

#### Test Procedure:
- Add **seven posts** on any topic of your choice.  
- Remove **two posts** as requested by the user.  
- Display all remaining posts.  
- Show the **total number** of posts.  
- Search for any **specific post** as requested by the user.  

---

### 2. BeanBuzz Queue Management System  

Design a **Queue Management System** for *BeanBuzz Coffee Shop* using a **Singly Linked List**.  
Each node will represent a customer’s **order details**.  

#### Operations:
1. **Place Orders:**  
   Add customer orders at the **end** of the queue with drink type and customizations.  
2. **Serve Orders:**  
   Serve customers **from the front** of the queue and remove them once completed.  
3. **Display Queue Status:**  
   Show the current queue with details such as **order number**, **drink type**, and **customizations**.  
4. **Display Specific Order Details:**  
   Show full details for a specific order, including **customer name**, **order type**, **customizations**, and **estimated wait time**.  
5. **Exit:**  
   End the program.  

---

### 3. Train Route Manager – Circular Linked List  

Develop a **Circular Linked List** to manage a **city train route system**.  
Each node represents a **train station**, and the route loops back from the last to the first station.  

#### Operations:
1. Add a new **station** to the circular route.  
2. Display the **entire route** of stations in a continuous loop.  

#### Use Case:
Simulate a train route where the train travels continuously without stopping at an “end” station.
