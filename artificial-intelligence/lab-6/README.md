# Lab 06: Genetic Algorithm

## Problem Statement
Using a Genetic Algorithm, find the maximum of the function f(x, y, z, w) = (x * 3y * 5z * 9w) / 35 where x, y, z, and w are genes that form a chromosome.

The program must display the best individual along with the best fitness, average fitness, and poorest fitness against each generation. The algorithm is designed using the following parameters:
* Number of generations: 35
* Population size: 10
* Mutation rate: 0.1
* Number of bits in each chromosome: 4
