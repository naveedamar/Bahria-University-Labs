# Artificial Intelligence Labs (AIL-201)

This directory serves as a comprehensive portfolio for the **Artificial Intelligence** lab at **Bahria University, Karachi Campus**. It documents my progress through foundational Python concepts, classical search algorithms, and advanced machine learning models.

---

## 🚀 About this Course
The curriculum is designed to transition from procedural programming to intelligent system design. Key milestones include:
* **Search Strategies:** Mastering Uninformed (BFS, DFS) and Informed (Greedy, A*) search.
* **Intelligence Paradigms:** Exploring Genetic Algorithms, Neural Networks (ANN), and Expert Systems.
* **Modern AI Applications:** Implementation of Computer Vision and Chat Bot logic.
* **Logic Programming:** Declarative programming using Prolog.

---

## 📂 Lab Directory Structure
The repository is organized by week. Each directory contains:
* `lab-tasks.ipynb`: Practical work and implementations completed during lab sessions.
* `tasks.ipynb`: Assignments and homework tasks provided for further exploration.

| Week | Lecture Title | Key Concepts |
| :--- | :--- | :--- |
| **01** | Introduction to Python | Variables, Basic Math, Formatted Output |
| **02** | Functions, Recursion, OOP | Recursive logic, Inheritance, Polymorphism |
| **04** | BFS and DFS | Uninformed Graph Traversal |
| **05** | Greedy & A* Search | Heuristic search and pathfinding |
| **06** | Genetic Algorithm | Optimization & Evolutionary Computing |
| **07** | Data Handling | NumPy, Pandas, and Data Processing |
| **08** | Decision Tree | Classification and Supervised Learning |
| **09** | ANN | Artificial Neural Networks |
| **10** | Expert System | Rule-based logic and Knowledge bases |
| **11** | Chat Bots | NLP and Dialogue Systems |
| **12** | Computer Vision | Image recognition and Processing |
| **13** | Prolog | Logic Programming & Symbolic AI |
