# AI Lab 02: Movie Ticket Booking System

---

## 📝 Task Description
The goal of this lab was to implement a Movie Ticket Booking System that asks the user for the following details:
* Age of the customer
* Day of the week
* Number of tickets to be purchased
* Student status (Yes/No)

The program calculates the total amount based on the following:
* **Ticket Prices:** Rs. 300 on weekdays (Monday to Friday) and Rs. 350 on weekends (Saturday and Sunday).
* **Surcharge:** 15% if booked on a weekend.
* **Student Discount:** 10% discount for students.
* **Group Discount:** 5% discount if 3 or more tickets are purchased.
