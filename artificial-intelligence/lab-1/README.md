# AI Lab 01: Python Foundations

---

## 📝 Overview
This lab covers the fundamental building blocks of Python, focusing on variable management, basic arithmetic operations, and formatted console output. These basics are essential for handling data in more complex AI algorithms later in the course.

## 🛠️ Tasks Performed

### Task 1: Employee Salary Calculation
A program to manage payroll data. It calculates the gross and net salary based on basic pay, allowances, and deductions.
* **Logic:** * `Gross Salary = Basic Salary + Allowance`
  * `Net Salary = Gross Salary - Deduction`

### Task 2: Movie Ticket Invoice System
A simple billing script that applies a 20% discount to a movie ticket and generates a formatted invoice.
* **Logic:** * `Discount Amount = Original Price * 0.20`
  * `Final Price = Original Price - Discount Amount`
