## 📝 Task 2: Movie Theatre Booking System
The goal of this task was to create a booking system using Object-Oriented Programming (OOP) that supports different seat types:
* **Seat Class:** A base class with attributes for seat number and type, and a method to calculate the price.
* **RegularSeat Class:** Inherits from the Seat class and uses the base ticket price.
* **VIPSeat Class:** Inherits from the Seat class and overrides the price calculation method to return a higher price.
