# 🖥️ COAAL - Lab 5

In this lab, we practice **string display, input handling, conditional checks, and comparison operations** in 8086 Assembly using **emu8086**.

---

## 🎯 Objectives

By completing this lab, students will be able to:

* Display strings and manage output formatting  
* Take user input through keyboard interrupts  
* Apply conditional logic to determine even/odd numbers  
* Compare numeric values and display results accordingly  

---

## 📝 Exercises

1. **String Display**  
   * Write a program to print two strings on separate lines.

2. **Even or Odd Checker**  
   * Prompt the user to enter a digit (0–9).  
   * Determine if the entered digit is even or odd.  
   * Display "Even" or "Odd" accordingly.

3. **Number Comparison**  
   * Take two inputs from the user.  
   * Compare them to check if they are equal.  
   * Display "Numbers are equal" or "Numbers are not equal."

---

## 📂 Key Concepts

* String and character display using `INT 21h`  
* Keyboard input handling  
* ASCII-to-decimal conversion  
* Conditional jumps and comparisons
