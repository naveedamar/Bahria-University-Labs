# 🖥️ COAAL - Lab 4

In this lab, we practice **validity of assembly instructions, data movement operations, and simple arithmetic programs** in 8086 Assembly using **emu8086**.

---

## 🎯 Objectives

By completing this lab, students will be able to:

* Identify legal and illegal assembly instructions
* Analyze effects of `MOV` instructions on operands
* Write simple programs to add and subtract byte-sized integers

---

## 📝 Exercises

1. **Instruction Legality Check**

   * Determine whether given assembly statements are legal or illegal, and provide reasons for illegal ones.

2. **MOV Instruction Effects**

   * Analyze the result of `MOV` instructions on 16-bit and 8-bit operands.

3. **Addition Program**

   * Write an assembly program to add two byte-size integers.

4. **Subtraction Program**

   * Write an assembly program to subtract two byte-size integers.

---

## 📂 Key Concepts

* Instruction legality in 8086
* Data transfer with `MOV`
* Operand size compatibility
* Basic arithmetic operations (addition, subtraction)

> **Note:** Task 1 and 2 were **theoretical**, thus no `.asm` (assembly) files are included in this directory.
