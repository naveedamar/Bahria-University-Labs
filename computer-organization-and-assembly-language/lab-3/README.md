# 🖥️ COAAL - Lab 3

**Course:** Computer Organization & Assembly Language

---

## 🎯 Objectives

By completing this lab, students will be able to:

* Perform basic input/output operations in assembly.
* Use variables to display strings.
* Implement arithmetic operations.
* Convert characters between uppercase and lowercase.

---

## 📝 Exercises

1. **Number Input & Display 🔢**

   * Take two numbers from the user.
   * Print them on the screen.

2. **Name Display 📝**

   * Store your full name in a variable.
   * Display it on the screen.

3. **Addition ➕**

   * Read two numbers from the user.
   * Add them together.
   * Display the result.

4. **Character Conversion 🔡**

   * Take a capital letter as input.
   * Convert it to the equivalent small letter.
   * Display it on the console.

---

## 📂 Key Concepts

* Input/Output handling in assembly
* String storage and display
* Arithmetic operations
* Character conversion (ASCII manipulation)
