# 🖥️ COAAL - Lab 3  

In this lab, we practice **basic input/output, string handling, arithmetic operations, and character conversion** using 8086 Assembly in **emu8086**.  

---

## 📌 Exercises
1. Take two numbers from the user and print them on the screen.  
2. Display your full name on the screen using a variable.  
3. Read two numbers, add them, and display the result.  
4. Convert a capital letter to its equivalent small letter and display it on the console.  

---

## ⚙️ Tools
- Emulator: emu8086  
- Mode: 16-bit Real Mode
