# 🖥️ COAAL - Lab 6

In this lab, we practice **looping structures and character sequence generation** in 8086 Assembly using **emu8086**.

---

## 🎯 Objectives

By completing this lab, students will be able to:

- Implement loops using the `LOOP` instruction.  
- Understand ASCII sequence iteration for both uppercase and lowercase letters.  
- Generate numeric and alphabetic output using loops.

---

## 📝 Exercises

1. **Alphabet Looping**
   - Use a loop to iterate through the lowercase alphabets (a–z).  
   - Use another loop to iterate through the uppercase alphabets (A–Z).  
   - Display both lowercase and uppercase sequences.

2. **Number Printing Loop**
   - Use a loop to print numbers from 1 to 9 sequentially.

---

## 📂 Key Concepts

- `LOOP` instruction in 8086 Assembly  
- ASCII character manipulation  
- Iterative printing with interrupts (`INT 21h`)  
- Control flow and repetition structures
