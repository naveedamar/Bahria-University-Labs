# 📘 COAAL Lab 01 – Number Systems and Assembly Basics

**Course:** Computer Organization & Assembly Language

---

## 🎯 Objectives

By completing this lab, students will be able to:

* Install and set up **emu8086** assembler.
* Perform **number system conversions** (binary, decimal, hexadecimal, two’s complement).
* Understand the **basic structure of an 8086 assembly program**.

---

## 📝 Exercises

1. **emu8086 Installation ⚙️**

   * Install emu8086 on your system.
   * Document each step with screenshots.

2. **Number System Conversions 🔢**
   Convert between number systems:

   * Hexadecimal → Binary
   * Binary → Decimal
   * Decimal → Binary
   * Negative Decimal → Binary (two’s complement)
   * Hexadecimal → Decimal
   * Decimal → Hexadecimal

3. **Assembly Program Structure 🖥️**
   Write a simple 8086 program to add two numbers:

   * Take two inputs from the user
   * Perform addition
   * Display the result on the screen

---

## 📂 Key Concepts

* Installation of emu8086
* Binary, Decimal, and Hexadecimal conversions
* Structure of 8086 Assembly programs
* Input, processing, and output in low-level programming
