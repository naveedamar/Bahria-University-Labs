# 💻 Information and Communication Technology (ICT) Coursework

Welcome to my ICT course repository! This collection houses all the practical assignments, exercises, and projects completed during my Information and Communication Technology course.

---

## 🎯 **Purpose of This Repository:**

* **Practical Skill Showcase:** To demonstrate hands-on proficiency in essential ICT tools and concepts.
* **Learning Documentation:** To systematically organize and document my learning journey in key IT areas.
* **Reference Point:** A personal archive for reviewing techniques in office productivity, networking fundamentals, and web development.

---

## 📚 **Course Focus & Key Areas Covered:**

This course provided a comprehensive introduction to critical ICT skills, with a primary focus on:

* **Microsoft Office Suite:**
    * **Microsoft Word:** Document creation, formatting, and advanced features.
    * **Microsoft Excel:** Data organization, formulas, functions, and basic data analysis.
    * **Microsoft Access:** Database design, data management, queries, forms, and reports.
    * **Microsoft PowerPoint:** Presentation design and delivery.
* **Networking Fundamentals:** Introduction to network concepts, topologies, protocols, and basic configurations.
* **Front-End Web Development:** Foundational skills in building the user-facing side of websites.

---

## 📁 **Repository Structure:**

This repository is organized into individual lab folders, from `Lab 1` through `Lab 13`. Each folder typically contains:

* **`Lab [Number]`**: (e.g., `Lab 1`, `Lab 2`, `Lab 13`)
* **Project files**: The `.docx`, `.xlsx`, `.accdb`, `.pptx`, `.html`, `.css`, or other relevant files for that specific lab.
* A brief `README.md` (optional, but recommended for more complex labs) explaining the lab's objective or key takeaways.
