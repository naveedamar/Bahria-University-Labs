# 📘 Lab04: SQL Functions-II

## 🎯 Objectives
Learn the use of **Multiple Row Functions** in `SELECT` statements.

## 📝 Exercises
Using the **StudentInformation** database, write SQL queries for:

1. Display the Job and **Average Salary** of all designations.  
2. Display **Maximum, Minimum, Sum, and Average Salary** of each job type.  
3. Display job titles where **Average Salary (Basic + House Rent)** is greater than 150K.  
4. Select designation and **Maximum Salary** where it is greater than 250K. Show in **descending order**.  
5. Display **Average Salary** of teachers with respect to their manager.  
6. Display the **Total Number of employees** who have no house allowance.  
7. Display **Job Title** and the **number of faculty** at that job position.  
8. Display the **difference between Highest and Lowest salaries**.  
9. Display the **manager number** and the **lowest salary** for that manager. Exclude unknown managers. Sort **descending**.  
10. Display job, **Number of Employees**, and **Average Salary (Basic + House Rent)** for each job. Round average salary to **two decimals**.
