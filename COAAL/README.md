# 🖥️ Computer Organization & Assembly Language (COAAL) Labs  

This directory contains my lab work for **Computer Organization and Assembly Language (COAAL)**.  
The goal is to build a solid understanding of low-level programming concepts such as registers, interrupts, memory management, and assembly language programming step by step.  

> **Note:** All programs are written in **8086 Assembly** and tested using the **emu8086 emulator**.  
> This directory is part of my main university repository.  

---

## 📚 Topics Covered
- Introduction to 8086 Architecture  
- Registers (AX, BX, CX, DX, SP, BP, SI, DI)  
- Data Movement Instructions  
- Input and Output using `INT 21H`  
- Arithmetic Operations  
- Control Flow (Jumps, Loops, Conditions)  
- Procedures  
- Working with Strings  
- File Handling (later)  

---

## ⚙️ Tools
- Emulator: [emu8086](https://emu8086-microprocessor-emulator.en.softonic.com/)  
- Mode: 16-bit Real Mode  

---

## 🚀 How to Run
1. Open `emu8086`.  
2. Load the `.asm` file.  
3. Compile and run in the emulator.  
4. View output in the emulated screen/console.
