# 📊 Data Structures and Algorithms (DSA)

This repository contains my coursework, assignments, and practical exercises from my Data Structures and Algorithms course. It serves as a personal archive for documenting my learning and demonstrating my ability to implement fundamental algorithms.

The topics covered include:

* **Linear Data Structures:** Arrays, Linked Lists, Stacks, and Queues.
* **Non-Linear Data Structures:** Trees, Heaps, and Graphs.
* **Algorithms:** Searching, Sorting, and Graph traversal algorithms.
