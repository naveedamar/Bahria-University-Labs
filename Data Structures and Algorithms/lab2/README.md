# 🔍 DSA Lab 02 – Searching Algorithms

**Course:** CSL-221 Data Structures & Algorithms 

---

## 🎯 Objectives
By completing this lab, students will be able to:
- Implement **Linear Search** in C++  
- Implement **Binary Search** in C++  

---

## 📝 Exercises

1. **Student’s Height Search**  
   Write a C++ program to apply **Binary Search** on a sorted list of student heights to quickly find a specific height.  

2. **Gem Hunt in a Treasure Chest**  
   Create a C++ program where the player searches for a chosen gem (e.g., Sapphire, Ruby, Diamond, Emerald) inside the legendary **GemChest**, displaying either its occurrence count or a "not found" message.  

3. **Search in FlavorRush’s Menu**  
   Implement a menu search feature for a fast-food chain (**FlavorRush**) that lets customers search for items (burgers, sides, beverages). If found, display the item with its location(s); otherwise, show that it is not offered.  

4. **Searching an Item in a Website (Superior Shopping)**  
   Build a search system for an e-commerce store with a product dataset (20 items):  
   - Use **Binary Search** to find products by **price** (show ID, name, price, and position).  
   - Use **Linear Search** to find the product `"Prod_x"` by name.  

---

## 📂 Key Concepts
- Binary Search  
- Linear Search  
- Real-world applications of search (sports selection, games, fast food menus, e-commerce)
