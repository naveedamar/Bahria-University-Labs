# OS Lab 06: Python and OS Interface

Exploring Python fundamentals and system-level interactions in the Ubuntu environment.

## Problem Statements

### Exercise 1: Python Fundamentals
Development of logic-based scripts to master Python control flow and data types.
* **Multiplication Table:** Generating tables for any number and custom range.
* **Basic Calculator:** Performing arithmetic operations based on user input.
* **Multiplication (No Operators):** Implementing multiplication using bitwise or additive logic.
* **Roman Numeral Converter:** Converting integers into Roman numerals (e.g., 234 to ccxxxiv).

### Exercise 2: Operating System Interface
Direct interaction with the Linux kernel and file system using the `os` and `platform` modules.
* **Process Metadata:** Retrieving PID, PPID, User ID, and Group ID.
* **Directory Management:** Programmatically creating and removing directories.
* **Environment Exploration:** Fetching the Present Working Directory (PWD) and system environment variables.
* **System Identity:** Displaying the OS name and current synchronized system time.

---

## Requirements
* **Environment:** Ubuntu (Linux)
* **Language:** Python 3.x
