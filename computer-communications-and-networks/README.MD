# 🌐 Computer Communications and Networks (CCN) 
### Course Code: 223

This directory contains selected **Cisco Packet Tracer (.pkt)** for the *CNN* course.  
The goal is to understand essential networking concepts and gain practical experience in network design, configuration, and troubleshooting.

> ⚠️ This course includes extensive theoretical content. Only labs and exercises that require creating or using `.pkt` files are uploaded here.

## 📘 Topics Covered
- Basics of computer communication and data transmission  
- Network devices and topologies  
- OSI and TCP/IP models  
- IP addressing and subnetting  
- Routing and switching fundamentals  
- VLANs and troubleshooting  

## ⚙️ Tools Required
- **Cisco Packet Tracer** (version 8.2 or later)

## 🚀 How to Use the Labs
1. Clone or download this repository.  
2. Open computer-communications-and-networks directory.
3. Locate the `.pkt` file you want to open.  
4. Open **Cisco Packet Tracer** on your system.  
5. Click **File → Open**, then select the `.pkt` file.  
6. Follow the lab topology and configure devices as instructed.  
7. To save your progress, click **File → Save As** and store it locally.  

> 💡 If you are viewing this on GitHub, download the `.pkt` file before opening it in Packet Tracer.

## 🧠 Learning Goal
Gain hands-on experience in designing, configuring, and managing small-scale computer networks.
