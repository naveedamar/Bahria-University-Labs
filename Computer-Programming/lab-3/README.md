# Lab 3 – Conditional Statements in C++  
**Course:** CSL-113 : Computer Programming  

## Task 1: Character Classification  
Write a C++ program that checks if a given character is:  
- Vowel  
- Consonant  
- Digit  

The program should ask the user for input and display the classification.  

---

## Task 2: Shopping Cart  
Create an online shopping discount system.  
- If purchase amount > 15000, apply **10% discount**.  
- Otherwise, show original amount.  

---

## Task 3: Age Analysis  
Three friends want to go on a zip line adventure.  
Write a program to:  
- Input ages of 3 friends.  
- Find and display the **youngest one**.  

---

## Task 4: Ticket Reservation System  
A bus has **35 seats**.  
- Ask user to enter number of seats required.  
- If seats are available, reserve them and update remaining seats.  
- If seats requested exceed availability, show a message that not enough seats are available.  

---

## Task 5: Medical Diagnosis System  
Take **body temperature** as input and classify:  
- Less than 36.5 → Hypothermia  
- 36.5 – 37.5 → Normal Body Temperature  
- 37.6 – 38.5 → Low-Grade Fever  
- More than 38.5 → High Fever
