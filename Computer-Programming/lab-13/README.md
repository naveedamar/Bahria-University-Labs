# Lab 13

## Task 1: Backup System
Create a program that copies the contents of the main catalog file to a backup file to preserve library data.

## Task 2: Motivational Quote Generator
A program where users input a four-word quote. The program then displays the quote in uppercase as output and stores it.

## Task 3: Student Record Management System
A menu-driven program for managing student records. It should allow adding new student records and displaying existing records.
