# Lab 10 – String Handling and Text Processing

---

## Task 1: Greeting Card Company
Imagine a greeting card company that allows customers to personalize their greeting cards with custom messages. One of the features provided is the ability to replace specific words in messages with other words.  

Develop a C++ program that lets customers replace chosen words in their greeting card messages (e.g., replace "Birthday" with "Anniversary" or "Congratulations" with "Well Done").  

---

## Task 2: Feature Enhancement
You are developing a feature for a social media platform that compares two different messages. Since users have character limits, they want to know which message is shorter.  

Write a C++ program that:  
- Takes two input strings from the user  
- Compares their lengths  
- Prints the shorter string  
- If both are equal in length, print `"equal"`  

---

## Task 3: Customer Service
Customer service agents need to combine different parts of responses into a complete message.  

Write a C++ program that:  
- Accepts multiple parts of a response as input  
- Concatenates them into a single message  
- Displays the complete response  

---

## Task 4: Text Processing Application
Develop a C++ program that:  
- Takes an input string from the user  
- Copies it into another empty string  
- Displays the copied string to the user  

---

## Task 5: Capitalize Words in a Sentence
Write a program that takes a paragraph as input and formats it into a well-structured output.  

Requirements:  
- Prompt the user to enter a sentence  
- Convert the first letter of each word to uppercase  
- Ensure proper spacing between words  
- Display the modified sentence
