## Task 1: Matrix Operations
Write a C++ program that takes two user-defined 2 × 2 matrices and performs these operations:
- Addition
- Subtraction
- Multiplication
- Inverse (for each 2×2 matrix, if the inverse exists)

Display the results for each operation.

---

## Task 2: Students Grades Organization (Transpose)
You have a matrix where each row represents a student and each column represents an assignment. The grading system requires rows to represent assignments and columns to represent students.

Write a C++ program that:
- Reads the original matrix of student grades (students × assignments)
- Computes the transpose so rows become assignments and columns become students
- Prints the transposed matrix
- Calculates and displays the average grade for each assignment (each row in the transposed matrix)

## Task 3: Professional Event Management – Seating Arrangement
Design a **menu-driven C++ program** to manage seating at a professional networking event. Features should include:
1. Seat Reservation: allow attendees to reserve seats by profession (Finance, Marketing, Engineering)
2. Count of each professional field attending: show real-time counts
3. Count of available seats: show how many seats remain

The program should allow repeated operations until the user chooses to exit.

---

## Task 4: Tic-Tac-Toe
Create a C++ program for a two-player Tic-Tac-Toe game using a 3 × 3 2D array. The program should:
- Allow two players to take turns entering moves
- Validate moves (no overwrite, valid positions)
- Display the board after each move
- Check for a winner or a draw and display the result
- Offer an option to play again
