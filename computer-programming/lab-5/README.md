# Lab 5 – Functions in C++  
**Course:** CSL-113 : Computer Programming  

## Objective(s)  
Upon completion of this lab session, learners will be able to:  
- Understand the concept of functions in C++.  
- Differentiate between functions and methods.  
- Use functions to improve **code reusability** and structure.  
- Implement programs using functions with return values, side effects, and parameter passing.  

---

## Task 1: Basic Calculator  
Create a **basic calculator** program that performs arithmetic operations on two numbers.  
- Operations: Addition, Subtraction, Multiplication, Division, Power.  
- Each operation must be implemented in a **separate function**.  

---

## Task 2: ATM System  
Create a simple **ATM system** that allows users to:  
- Check balance  
- Deposit funds  
- Withdraw funds  

**Requirements:**  
- Use **functions** to perform each operation.  
- Use **if-else ladders** to validate input (e.g., withdrawals should not exceed available balance).  
- Use **loops** to allow multiple transactions until the user chooses to exit.  

---

## Task 3: Number Analysis  
Write a program with functions to:  
- Find the **least significant digit (LSD)** of a 3-digit number.  
- Find the **most significant digit (MSD)** of a 3-digit number.  
- Check if the number is a **palindrome**.  

---

## Task 4: Driving Eligibility  
Design a program to assess a person’s **driving eligibility** based on:  
- Age  
- Vehicle type (Car or Motorcycle)  
- Valid driving license possession  

**Criteria:**  
- Minimum age for car → 18 years  
- Minimum age for motorcycle → 16 years  
- Driving a car requires a valid license  
- Follow local regulations for motorcycle driving  

The program should display the eligibility status.
