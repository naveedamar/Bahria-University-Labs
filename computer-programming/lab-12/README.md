# Lab 12 – Pointers and Call by Reference

---

## Task 1: Student Information Swap
You are managing student information for a school.  
Your task is to implement a function that swaps the information of two students.  

This task will help you understand how **pointers** can be applied to real-world problems.  

---

## Task 2: Managing Expenses
Imagine you're managing expenses for a grocery shopping trip with your friends.  

Your task is to:  
- Develop a function that computes the **total expenditure** and **average spending per person**.  
- Accept an array of integers representing the amounts spent by each person.  
- Use **call by reference with pointers** to process the data.  

**Output Requirement:**  
Print the total expenditure and average spending per person to provide a summary of the grocery shopping expenses.
