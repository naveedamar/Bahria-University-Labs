# Lab 7 – Arrays in C++  
**Course:** CSL-113 : Computer Programming  

## Objective(s)  
Upon completion of this lab session, learners will be able to:  
- Understand and apply arrays in solving real-world problems.  
- Use arrays with loops for storing, processing, and displaying data.  
- Perform array manipulations such as rotations, reversals, and validations.  

---

## Task 1: Online Food Ordering  
Develop an **online food ordering system** for a restaurant chain.  
The program should:  
- Allow customers to browse menu items.  
- Select items and place an order for delivery or pickup.  
- Use **arrays** to store menu items and selections.  
- Implement **error handling** for invalid inputs.  

---

## Task 2: Rotational Clock  
Create a digital clock program with rotation functionality.  
- Store time as **hours, minutes, seconds** in an array.  
- Ask the user whether to rotate time **left** or **right**.  
- Update the array accordingly.  
- Display the updated time on the digital clock.  

---

## Task 3: Data Analyzer  
Develop a program to analyze manufacturing data stored in arrays.  
- Prompt the user to enter array elements.  
- Stop input when the array has **no zero values**.  
- Print arrays that contain **no zero entries**.  

---

## Task 4: Survey Analysis  
Create a survey result analyzer for product ratings.  
- Ask 10 participants to enter ratings (1–10).  
- Store ratings in an array.  
- Create another array to store ratings in **reverse order**.  
- Print the reversed ratings for analysis.
