# Lab 4 – Loop-Based Programming Tasks

## Task 1: Converter (Numeric – Alphabets)  
Write a program using a **for loop** that prints ASCII values and their equivalent characters:  
- Uppercase letters (A–Z)  
- Lowercase letters (a–z)  

---

## Task 2: Inventory Management  
A retail store needs a program to manage its stock.  
- Ask the user how many different items are in stock.  
- For each item, input price per unit and quantity.  
- Calculate and display the **total value of the inventory**.  

---

## Task 3: Odd Number Addition  
Create a program that:  
- Takes **10 integers** as input using a **for loop**.  
- Identifies odd numbers.  
- Calculates and displays the **sum of all odd numbers**.  

---

## Task 4: Multiplication Visualization  
Help students learn multiplication:  
- Ask the user to enter a number.  
- Use a **do-while loop** to display the multiplication table of that number.  

---

## Task 5: Academic Excellence Awards Ceremony  
Recognize student achievements by calculating factorials:  
- Input a student’s score.  
- Use a **loop** to calculate the **factorial**.  
- Display the factorial as the "complexity level" of problems solved.  

---

## Task 6: GCD/HCF Finder  
Write a program that finds the **Greatest Common Divisor (GCD)** or **Highest Common Factor (HCF)** of two numbers.  
- Use a **while loop**.  
- Input two numbers.  
- Display their GCD/HCF.
