# Lab 2 – Basic C++ Programming Tasks

## Task 1: World Travel Planner  
Write a C++ program to **convert distance from miles to kilometers**.  
Formula:  
`1 mile = 1.60934 kilometers`  

---

## Task 2: Bank Account Transactions  
Create a C++ program to perform the following transactions:  
- Withdraw **Rs. 2000**  
- Deposit **Rs. 10,000**  
Display the **account balance** after each transaction.  

---

## Task 3: Letter Design  
Write a program that prints a **big letter of your name’s initial** using the same letter.  
Example: Letter **H** made from multiple `H` characters.  

---

## Task 4: EXCEL Laboratories Receipt Generator  
Create a program that generates receipts for medical services.  

- Input: Service description, quantity, and service fee per unit.  
- Calculate:  
  `Total cost = quantity × fee per unit`  
- Apply **5% tax** on the bill.  
- Display a **detailed receipt**.
