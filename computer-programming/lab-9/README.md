# Lab 9 – Recursion, Comparison, and Function Overloading
**Department of Computer Sciences**  
**CSL-113: Computer Programming Lab**

---

## Task 1: Exponentiation Calculation
Write a C++ program that uses **recursion** to calculate the exponentiation of a number.  
- Input: base number and exponent from the user  
- Use a recursive function to compute the result  
- Display the final answer  

---

## Task 2: Number Comparison Utility
Design a C++ program that allows users to input **two, three, or four numbers** and then:  
- Find the smallest and largest among them  
- Support comparisons for different combinations (2, 3, or 4 numbers)  
- Display results accordingly  

---

## Task 3: Recursive Fibonacci Series
Write a C++ program that prints the **Fibonacci series** using recursion.  
- Input: N (number of terms)  
- Output: Fibonacci sequence up to N terms  

Example: For `N = 6`, output → `0, 1, 1, 2, 3, 5`

---

## Task 4: Finding the Maximum
Develop a program to find the maximum value using functions:  
- A function to find the maximum of **three floating-point numbers**  
- A function to find the maximum of **two integers**  

Use these functions to analyze sensor data and identify anomalies.  

---

## Task 5: Calculating Area with Different Shapes
Implement a **geometry calculator** using **function overloading**.  
- Calculate the area of a **circle** (input: radius)  
- Calculate the area of a **rectangle** (input: length and width)  
- Calculate the area of a **triangle** (input: base and height)  

The program should intelligently call the correct overloaded function based on user input.
